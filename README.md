### 1. Vấn đề
Cần tìm giáo trình "Nhập môn Công nghệ Thông tin" bản PDF chính thống của Học viện, tránh các trang web quảng cáo và yêu cầu trả phí.

### 2. Yêu cầu
- Sử dụng `filetype:`, `site:`, dấu ngoặc kép `" "` và toán tử trừ `-`.
- Loại bỏ ít nhất 2 trang web không mong muốn.
- Chụp ảnh 3 kết quả đầu tiên trên Google.

### 3. Cách làm
**Câu truy vấn:**
```text
"Nhập môn Công nghệ Thông tin" filetype:pdf site:ptit.edu.vn -scribd -123doc
```
